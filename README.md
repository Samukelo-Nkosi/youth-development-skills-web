## 📖 About the Project

The **Youth Skills Development Initiative** is a responsive website created to promote youth empowerment through free educational opportunities and career development programs.

The platform provides information about:

- 💻 Digital Skills
- 💡 Entrepreneurship
- 🛠️ Vocational Training
- 🌐 Information Technology (IT)

It enables visitors to:

- Learn about available programs
- Contact the organization
- Subscribe to newsletters
- Explore the organization's mission and impact

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Samukelo-Nkosi/Youth-Skills-Development.git
```

### Navigate into the project

```bash
cd Youth-Skills-Development
```

### Open

Simply open

```text
index.html
```

or run with VS Code Live Server.
